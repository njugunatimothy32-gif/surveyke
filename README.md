# SurveyKE 🇰🇪

A responsive survey earning platform for Kenyan users. Complete surveys about Kenyan brands and earn KES directly to your wallet.

![Status](https://img.shields.io/badge/status-live-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ Features

- 🔐 **Auto-login registration** — Create an account and get taken straight to the dashboard
- 🏢 **9 real surveys** — Jamaa, Naivas, Jumia, Bolt, M-Pesa, KCB, Equity, KPLC, and Mama Ngina University
- 💰 **Per-question rewards** — Earn KES for every answer (KES 300–800 per survey)
- 🎁 **Mandatory referral system** — Share on WhatsApp, refer 5 friends, earn KES 100 each
- 📊 **Progress bar** — Visual 0/5 → 100% referral progress
- 📱 **Copyable M-Pesa number** — One-tap copy button for error-free sending
- ✅ **Paste-and-verify activation** — Verify KES 100 payment by pasting M-Pesa message
- 💸 **Withdrawal** — Amount + phone + method → success message with "before midnight" guarantee
- 🔄 **Resume where you left off** — Automatic resume banner if you leave mid-flow
- 🆘 **Help & Support** — Contact Lucy Corporation support by email or WhatsApp
- 🔒 **Task locking** — Completed surveys, referrals, activation, and withdrawals cannot be redone
- 📱 **Fully responsive** — Mobile-first design

## 🎯 Withdrawal Requirements

Before a user can withdraw, they must complete **all 3 requirements**:

1. ✅ **Complete at least 1 survey**
2. ✅ **Refer 5 friends on WhatsApp** (progress bar fills to 100%)
3. ✅ **Activate account** (send KES 100 to 0734 872 045 via M-Pesa Send Money — refunded to wallet)
